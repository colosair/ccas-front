# CCAS - Civil Complaint Assistance System

민원분류지원시스템(CCAS, Civil Complaint Assistance System)은 Code 4급 비긴급 경찰 민원을 대상으로 통화 녹취와 민원 텍스트를 AI가 후처리하여 요약, 정리하고 유사 사례 기반으로 담당 부서 또는 타기관 이관 후보를 제안하는 경찰 내부 업무 보조 플랫폼입니다.

현재 저장소는 해커톤 MVP를 위한 정적 프론트엔드 프로토타입입니다. 실제 STT, LLM, RAG, 데이터베이스 연동은 기획 단계의 목표 아키텍처로 문서화되어 있으며, 화면에서는 주요 업무 흐름을 시연할 수 있도록 구성되어 있습니다.

## 프로젝트 배경

경찰 민원 창구에는 실제 경찰 소관 민원뿐 아니라 지자체, 소비자원, 안전신문고 등 타기관으로 이관되어야 하는 민원이 함께 유입됩니다. 비긴급 민원은 즉각적인 현장 출동보다 정확한 내용 파악, 소관 분류, 담당 부서 또는 타기관 안내가 중요합니다.

CCAS는 상담 담당자가 반복적으로 수행하는 통화 청취, 요약, 분류, 이관 판단 보조 업무를 AI로 지원하여 민원 처리의 효율성과 일관성을 높이는 것을 목표로 합니다.

## 핵심 기능

- 녹취 파일 업로드 기반 민원 등록
- 민원 텍스트 직접 입력
- STT 결과 검토 화면
- AI 템플릿 요약 결과 표시
- 핵심 키워드 및 누락 정보 표시
- 유사 사례 기반 Top-N 분류 후보 표시
- 담당 부서 또는 타기관 이관 후보 제안
- 담당자 최종 선택 및 수정 흐름
- 라이트/다크 테마 전환

## 화면 구성

| 파일 | 설명 |
|---|---|
| `index.html` | 담당자 홈 화면, 주요 지표, 최근 민원 목록 |
| `upload.html` | 신규 민원 등록, 녹취 업로드 및 텍스트 입력 |
| `stt-review.html` | STT 전사 결과 검토 및 수정 |
| `analysis.html` | AI 분석 결과, 분류 후보, 이관 후보 확인 |
| `style.css` | 공통 레이아웃, 디자인 토큰, 컴포넌트 스타일 |

## 실행 방법

이 프로젝트는 별도의 빌드 과정이 없는 정적 HTML/CSS 프로토타입입니다.

브라우저에서 `index.html` 파일을 직접 열어 확인할 수 있습니다.

로컬 서버로 실행하려면 다음 명령을 사용할 수 있습니다.

```bash
python -m http.server 8000
```

실행 후 브라우저에서 아래 주소로 접속합니다.

```text
http://localhost:8000
```

## 기획상 목표 아키텍처

현재 구현은 정적 프론트엔드이지만, 전체 서비스는 다음 구조를 목표로 합니다.

```text
Frontend
- 담당자 화면
- 녹취 업로드
- STT 결과 검토
- AI 분석 결과 카드

Backend
- 로그인/권한 관리
- 파일 업로드
- 민원 케이스 저장
- AI 서버 연동
- 결과 및 피드백 저장

AI Server
- STT 변환
- LLM 템플릿 요약
- 개인정보 및 민감정보 전처리
- 임베딩 생성
- RAG 기반 유사 사례 검색

Database
- PostgreSQL + pgvector
- 사용자/권한
- 민원 케이스
- 벡터 분류 기준
- AI 분석 결과
- 담당자 피드백
```

## AI 처리 흐름

```text
녹취 파일 또는 민원 텍스트 입력
↓
STT를 통한 음성 텍스트 변환
↓
담당자 전사문 검토
↓
LLM 기반 템플릿 요약
↓
정리본 임베딩 생성
↓
pgvector 유사도 검색
↓
Top-N 분류 후보 및 이관 후보 생성
↓
담당자 검토, 수정, 확정
↓
피드백 데이터 저장
```

## MVP 범위

### 포함 범위

- Code 4급 비긴급 민원 중심

- AI 요약 및 분류 후보 확인 화면
- 담당자 최종 검토 중심의 UX

- 현장 출동 여부 판단
- AI 단독 민원 처리 또는 이관
- 실제 개인정보 또는 경찰 내부 민감 데이터 사용
- 대규모 로컬 LLM 학습
- 민원인 직접 사용 서비스
